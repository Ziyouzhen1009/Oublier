# Oublier · 忘忧屿

> **在这里逃离真实的世界。**

`Oublier`（法语意为「遗忘」）是一款献给忙碌之人的氛围探索与弱社交心灵避难所。
没有打卡任务、没有红点焦虑、没有必须回复的聊天——你可以随时脱下现实里的身份，登上这座海上微光小岛，吹吹海风、烤烤火、听听雨声、与远处的陌生旅人保持恰到好处的距离，把烦恼留给海浪，把自己还给自己。

---

## v0.1 现已可玩功能

- **临时诗意身份**：每次登岛都可以自由更换一个不带现实标签的名字（如「3号车厢的听雨人」「凌晨的煮茶人」）。
- **忘忧屿漫步**：在响应式 2D 手绘氛围小岛上自由行走（支持 `WASD` / 方向键 或 鼠标点击/触屏移动），按 `E` / `空格` 或点击地标交互。
- **四处心境地标**：
  - **遗忘篝火**：写下今天想暂时忘掉的事投入火中——文字不会被保存，只会化作火星升向夜空。
  - **潮汐栈桥**：从海面捞起远方旅人的漂流瓶，为对方点亮一盏小灯；也可以写下只属于此刻的只言片语投入大海。
  - **观星石阶**：回答一个温柔而不说教的小问题，在「记忆匣」里慢慢拼出属于自己的内在回声。
  - **静谧长椅**：跟随柔和的 4-4-6 呼吸节律静坐片刻，让紧绷的身体先慢下来。
- **独自一人，但知道远处有人**：岛上有三位安静的旅人（煮茶人、听海者、观星客）各自发呆或散步。你可以走近递一杯热茶、并肩待一会儿，或轻声聊几句——且所有对话会在天亮后自动遗忘。
- **纯 Web Audio 实时声景**：内置零外部音频依赖的程序化环境音（海浪潮汐、细雨、篝火噼啪、五声音阶星铃），支持独立调音。
- **三种心境天色 & 发呆模式**：自由切换「星夜」「细雨」「拂晓」；开启「发呆模式」隐藏所有界面控件，纯粹看海与星空。

## 立即运行

本项目采用 **零构建（Zero-Build）纯前端架构**（HTML5 + CSS3 + Vanilla JS + Canvas 2D + Web Audio API）：

1. **直接打开**：双击仓库根目录下的 `index.html`，即可在任意现代浏览器中离线运行。
2. **本地静态服务器预览**（可选）：任意静态文件服务器均可托管根目录。
3. **部署到 GitHub Pages**：
   - 进入仓库 `Settings -> Pages`
   - `Source` 选择 `Deploy from a branch`，分支选择 `main`，目录选择 `/ (root)`
   - 保存后即可通过 `https://ziyouzhen1009.github.io/Oublier/` 直接访问并分享给朋友。

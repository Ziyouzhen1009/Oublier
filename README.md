# Oublier 

> **在这里逃离真实的世界。**

`Oublier`（法语意为「遗忘」）是一款献给忙碌之人的 3D 哥特氛围探索与弱社交心灵避难所。
没有打卡任务、没有红点焦虑、没有必须回复的聊天——你可以随时脱下现实里的身份，踏上这座寂静的海上哥特修道院，在尖拱石廊、玫瑰窗钟楼与夜海之间散步发呆，把烦恼留给圣火，把自己还给自己。

---

## v0.3 · 多彩哥特庭园与纯鼠标俯视漫步特性

- **写实接地 3D 披风旅人建模**：采用低面雕塑折面风格的 3D 角色（玩家与四位同行旅人），带有双关节皮革短靴、贴地多层接触阴影、交替支撑写实步态、随风飘动的分段围巾与摆动提灯。
- **多彩哥特材质与六大主题区**（采用类似《英雄联盟》的高俯视柔和跟随视角，全程只需鼠标左键点击/按住牵引移动、滚轮缩放远近，走近地标或旅人后左键点击交互，彻底解放双手）：
  1. **遗忘圣火坛（中央镶金拼花庭院）**：写下今天想暂时忘掉的事投入圣火——文字不会被保存，只会化作火星升向石拱之上。
  2. **观星钟楼（北方星盘高台与宝石玫瑰窗）**：登上十二级石阶，在宝石彩绘玫瑰窗与地面绚丽彩光下回答温柔的小问题，将思绪化作夜空星光存入「记忆匣」。
  3. **潮汐石栈桥（南方水门与旧木栈道）**：穿过水门石拱，在风化旧木栈道旁打捞远方旅人的漂流瓶并点亮微灯，或写一句话投入 3D 夜海。
  4. **柏林石亭（东方银杏蔷薇秘境园）**：在摇曳的翠柏、暖金银杏与深红蔷薇旁静坐，跟随 4-4-6 呼吸引导让身心慢下来。
  5. **回声长廊（西方古典棋盘大理石柱廊）**：听过往旅人留下的石廊低语，敲响悬吊黄铜风钟。
  6. **孤灯望海台（东南紫鸢尾花坡灯塔）**：切换全景远眺视角，从高处静静俯瞰整座哥特修道院与夜海。
- **独自一人，但知道远处有人**：四位 3D 旅人（`凌晨的煮茶人`、`听海的影子`、`不看表的观星客`、`修道院抄书人`）在岛上各自游走。可走近递热茶、并肩发呆或轻声对话——所有对话天亮后自动遗忘。
- **纯 Web Audio 实时声景 & 三种心境天色**：实时合成海浪、细雨、篝火、五声音阶星铃与风钟；支持切换「星夜」「细雨」「拂晓」与「发呆模式」。

## 立即运行

本项目已离线打包 `vendor/three.min.js`（Three.js r147），采用 **零构建（Zero-Build）纯前端架构**：

1. **直接打开**：双击根目录下的 `index.html`，即可在现代浏览器中直接运行（支持离线 `file://` 与桌面端/移动端浏览器）。
2. **部署到 GitHub Pages**：
   - 进入仓库 `Settings -> Pages`
   - `Source` 选择 `Deploy from a branch`，分支选择 `main`，目录选择 `/ (root)`
   - 保存后即可通过 `https://ziyouzhen1009.github.io/Oublier/` 直接访问。

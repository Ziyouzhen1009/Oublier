# Oublier 演进路线图 (Roadmap)

> 核心原则：**永远保持克制、低压力、不制造新的社交焦虑与数字负担。**

---

## v0.1 · 忘忧屿初登（当前版本）

**目标**：让任何忙碌的人打开即可进入一个完整、自洽、宁静的心灵空间，即便只有自己一个人，也能感受到温和的陪伴。

- **零构建纯本地运行**：HTML5 Canvas 2D + Web Audio API，双击 `index.html` 或托管在 GitHub Pages 即可体验。
- **忘忧屿世界**：
  - 4 个核心地标：遗忘篝火、潮汐栈桥（漂流瓶）、观星石阶（自我对话）、静谧长椅（呼吸引导）。
  - 3 位环境旅人：煮茶人、听海者、观星客，支持「递茶 / 并肩发呆 / 轻声短聊」。
  - 3 套心境天色：星夜（Midnight）、细雨（Rainy）、拂晓（Dawn）。
  - 纯粹的「发呆模式」（Zen Mode）与独立声景混音台。
- **记忆匣**：本地持久化自省笔记与收藏漂流瓶，支持一键导出 Markdown 或「彻底遗忘」清空。

---

## v0.2 · 远方的真实现场（异步 + 轻实时后端）

**目标**：在 `src/storage.js` 已预留的数据接口之上，接入轻量无服务器后端（如 Supabase 或 Cloudflare Workers + D1/KV），实现真正的人与人之间的微弱连接。

- **真实世界漂流瓶池**：
  - 用户投入大海的漂流瓶可被另一位陌生旅人捞起并「点亮一盏灯」。
  - 保留匿名与随机身份，不展示主页、粉丝数与历史轨迹。
- **匿名微光同步（Presence）**：
  - 同一时刻在岛上的真实用户化作海边或树影下安静的「微光剪影」，不强制打招呼。
  - 若两人同时坐在同一处篝火旁，可发起限时且**天亮/离线即焚**的轻声对谈。
- **极简内容安全机制**：温和的敏感词过滤与静默屏蔽，守护空间纯粹度。

---

## v0.3 · 一键躲进去（桌面常驻 + 移动端 PWA）

**目标**：让工作或学习间隙的「逃离」更加自然、随手可得。

- **桌面端轻量避难所（Tauri）**：
  - 常驻 Windows / macOS 系统托盘，压力大时快捷键一键呼出全屏或小窗，播放雨声与海浪。
  - 无需浏览器的极低内存占用。
- **移动端 PWA**：
  - 支持添加到手机主屏幕，提供触控摇杆/单手点按漫步与睡前白噪音定时关闭。
- **更多岛屿季节与自然音效**：秋叶林风、冬夜壁炉雪声、虫鸣夏夜等。

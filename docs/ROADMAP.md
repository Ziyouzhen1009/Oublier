# Oublier 演进路线图 (Roadmap)

> 核心原则：**永远保持克制、低压力、不制造新的社交焦虑与数字负担。**

---

## v0.1 · 忘忧屿初登（已完成）

- 零构建 2D Canvas 可玩原型，确立「遗忘篝火 / 漂流瓶 / 观星自省 / 呼吸长椅 / 偶遇旅人」核心循环。

---

## v0.2 · 极简 3D 哥特圣所（当前版本）

**目标**：以简洁雕塑感的 3D 人物与哥特建筑营造更有沉浸感的心灵避难所，并扩大可探索空间。

- **离线 3D 引擎**：内置 `vendor/three.min.js`（Three.js r147），零构建直接打开。
- **极简 3D 人物**：低面折面斗篷、哥特尖顶兜帽、微光双眸、迈步动作、飘动围巾与随身提灯。
- **扩大的哥特修道院六大区域**：
  - 遗忘圣火坛（中央八角尖拱庭院）
  - 观星钟楼（北方十二级石阶 + 发光玫瑰窗 + 旋转星象仪）
  - 潮汐石栈桥（南方哥特水门）
  - 柏林石亭（东方柏树林 + 残拱）
  - 回声长廊（西方六跨尖拱柱廊 + 黄铜风钟）
  - 孤灯望海台（东南悬崖灯塔 + 全景远眺视角）
- **实时罗盘小地图**与 360° 拖拽旋转 / 滚轮缩放第三人称相机。

---

## v0.3 · 远方的真实现场（异步 + 轻实时后端）

**目标**：接入轻量无服务器后端（Supabase 或 Cloudflare Workers），实现真正的陌生人异步与即时微弱连接。

- 真实跨设备漂流瓶池与点亮微灯。
- 同一时刻在修道院里的真实旅人化作远处带有斗篷与提灯的 3D 剪影；同处圣火坛旁可开启「天亮即焚」的轻声对谈。

---

## v0.4 · 一键躲进去（桌面常驻 + 移动端 PWA）

- Tauri 轻量化桌面托盘版本，工作压力大时一键躲进哥特修道院听雨看海。
- 移动端 PWA 支持与更多季节天气（初雪夜教堂、秋叶庭院）。
